# from-assembly-to-ai

> 10 年 Java 工程师重学计算机底层：汇编 → 微机原理 → 网络编程 → ROS2 → 人工智能。
> 全部学习笔记、代码与实验，与公众号文章、B 站实操视频配套。

## 为什么重学

写了 10 年企业级 Java（Spring / 微服务 / MySQL / Redis / Neo4j / Elasticsearch），离"计算机"却越来越远——JVM 屏蔽了内存地址、寄存器和一切硬件细节。现在转型高校计算机教师，要给学生讲《微机原理》，长期方向是机器人编程（ROS2）。于是决定从最底层开始，老老实实重学一遍，并把全过程公开。

如果你也是"应用层写久了、想往下沉一沉"的程序员，或者正在学这些课程的学生，欢迎一起走。
