# 第 2 章 · 寄存器初识与第一条汇编指令

> 配套笔记 01：《写了 10 年 Java，我发现自己根本不懂 CPU——汇编重学笔记 01》
> 对应教材第 1、2 章：机器语言与汇编、存储器与三总线、通用寄存器、物理地址 = 段地址 × 16 + 偏移地址、CS:IP。

## 目标

在 DOSBox 的 debug 工具中输入并单步执行人生第一批汇编指令，亲眼观察寄存器随指令变化。

## 完整操作记录

启动 DOSBox 后：

```
mount c d:\dos        :: 挂载 debug.exe 所在目录（按实际路径修改）
c:
debug                 :: 进入 debug，出现 "-" 提示符
```

在 debug 中依次操作：

**1. 查看寄存器**

```
-r
```

输出示例（数值因环境而异）：

```
AX=0000  BX=0000  CX=0000  DX=0000  SP=FFEE  BP=0000  SI=0000  DI=0000
DS=073F  ES=073F  SS=073F  CS=073F  IP=0100   NV UP EI PL NZ NA PO NC
```

**2. 写入汇编指令**

```
-a
073F:0100 mov ax, 1
073F:0103 mov bx, 2
073F:0106 add ax, bx
073F:0108            （此处直接回车，结束输入）
```

**3. 单步执行，逐条观察**

```
-t        :: 执行 mov ax, 1  → AX 变为 0001
-t        :: 执行 mov bx, 2  → BX 变为 0002
-t        :: 执行 add ax, bx → AX 变为 0003（1 + 2）
```

**4. 反汇编验证（可选）**

```
-u 0100
```

可以看到刚才输入的三条指令及其机器码，直观感受"汇编指令与机器码一一对应"。

**5. 退出**

```
-q
```

## 思考点

- 为什么 8086 寄存器只有 16 位，却能寻址 1MB（20 位地址总线）？—— 段地址 × 16 + 偏移地址
- `-u` 反汇编结果里，`mov ax, 1` 对应的机器码是什么？试着和教材中的指令格式对照
- 内存中的字节是"指令"还是"数据"，由什么决定？—— CS:IP 是否指向它
